# 📖 English Window - Interactive Vocabulary Learning Platform

**English Window** is a dynamic, user-friendly, and interactive web application designed to help users expand their English vocabulary through structured lessons, audio pronunciations, instant search, and detailed word insights.

---

## 🚀 Key Features

* **Categorized Lessons:** Words are organized by levels (`Learn - 1`, `Learn - 2`, etc.), allowing users to learn progressively.
* **Text-to-Speech Audio:** Built-in Browser Web Speech API allows users to listen to the correct English pronunciation of any word by clicking the volume button.
* **Detailed Word View (Modal):** Clicking the info `(i)` button opens a modal window displaying comprehensive details, including word meaning, example sentences, and synonyms.
* **Live Word Search:** A real-time search engine that lets users quickly search for any specific vocabulary across the entire database.
* **Interactive UI Feedback:** Includes active lesson button highlighting and a smooth loading spinner during API data fetching.
* **Responsive Design:** Optimized with a responsive grid layout that adapts seamlessly across mobile, tablet, and desktop viewports.
* **Frequently Asked Questions (FAQ):** Includes an interactive accordion section to assist users with common queries.

---

## 🛠️ Tech Stack & Libraries

* **HTML5:** Semantic layout and structural elements.
* **Tailwind CSS & DaisyUI (v5):** Responsive styling, grid system, cards, modals, and accordion components.
* **JavaScript (ES6+):** Async/Await API fetching, dynamic DOM manipulation, search filtering, and Web Speech API Integration.
* **Font Awesome:** Icons for interactive UI elements.
* **REST API:** Powered by the Programming Hero Open Learning API.
